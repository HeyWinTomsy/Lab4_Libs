# MathUtils SDK

## 1. Призначення

MathUtils — бібліотека C++ для чисельного розв'язання задачі Коші для звичайного диференціального рівняння:

\[
y' = x^2 y, \qquad y(x_0)=y_0.
\]

Бібліотека надає метод Ейлера, метод Рунге — Кутти четвертого порядку, універсальну функцію розв'язання та оцінку різниці між результатами двох методів.

## 2. Підключення

```cpp
#include "MathUtils.h"
```

Для роботи програми необхідно підключити імпортну бібліотеку під час компонування та забезпечити доступність `MathUtils.dll` під час виконання.

## 3. Опис API

### `double Euler(double x0, double y0, double h, int n)`

**Призначення:** чисельне розв'язання рівняння методом Ейлера.

**Параметри:**
- `x0` — початкове значення незалежної змінної.
- `y0` — початкове значення шуканої функції.
- `h` — крок інтегрування.
- `n` — кількість кроків.

**Повертає:** наближене значення функції після виконання `n` кроків.

### `double RungeKutta4(double x0, double y0, double h, int n)`

**Призначення:** чисельне розв'язання рівняння методом Рунге — Кутти четвертого порядку.

**Параметри:** `x0`, `y0`, `h`, `n` мають те саме значення, що й у функції `Euler`.

**Повертає:** наближене значення функції після `n` кроків.

### `double solve(double x0, double y0, double h, int n)`

**Призначення:** універсальна функція розв'язання задачі Коші.

**Повертає:** результат функції `RungeKutta4` з тими самими параметрами.

### `double estimateError(double x0, double y0, double h, int n)`

**Призначення:** порівняння результатів методу Ейлера та методу Рунге — Кутти четвертого порядку.

**Повертає:**

`abs(RungeKutta4(...) - Euler(...))`

Це різниця між результатами методів, а не гарантована абсолютна похибка відносно точного розв'язку.

## 4. Вхідні дані та граничні умови

- `x0`, `y0` і `h` повинні бути скінченними числовими значеннями.
- Для коректного покрокового інтегрування `h` має бути ненульовим.
- `n` має бути невід'ємним цілим числом.
- При `n = 0` функції повертають початкове значення `y0`.
- Від'ємне `n` у поточній реалізації також призводить до повернення `y0`, оскільки цикл не виконується; таке використання не рекомендується.
- Бібліотека не перевіряє ці умови автоматично.
- Для великих значень параметрів можливі переповнення числового типу `double` та накопичення чисельної похибки.

## 5. Вимоги до середовища

- Компілятор C++ із підтримкою C++20.
- Заголовковий файл `MathUtils.h`.
- Імпортна бібліотека, сумісна з компонувальником користувача.
- Динамічна бібліотека `MathUtils.dll`, доступна під час виконання.

## 6. Приклад використання

```cpp
#include <iostream>
#include "MathUtils.h"

int main() {
    double result = MathUtils::RungeKutta4(
        0.0, 1.0, 0.1, 10
    );

    std::cout << result << '\n';
    return 0;
}
```
